# El Camino Bayesiano

*El Camino Bayesiano* es un libro de Estadística Bayesiana dirigido a estudiantes de Estadística, ciencia de datos, matemáticas y áreas afines, así como a estudiantes de posgrado interesados en profundizar en este enfoque de la inferencia estadística. Se asume que el lector está familiarizado con los fundamentos de la estadística frecuentista y el análisis de regresión, y que posee conocimientos básicos de un lenguaje de programación como R o Python.

El libro busca mantener un equilibrio entre la teoría, la implementación computacional y la aplicación práctica. Su contenido comienza con los fundamentos de la Estadística Bayesiana y avanza progresivamente hacia modelos y métodos más sofisticados.

A lo largo de los capítulos se presentan ejemplos y aplicaciones basados en casos reales, acompañados de explicaciones detalladas y código reproducible. Todo el código utilizado en las secciones, ejemplos y ejercicios aplicados se encuentra disponible abiertamente en este repositorio.

El libro puede descargarse gratuitamente en [este enlace](https://sites.google.com/view/juansosa/the-bayesian-way).

El código en R y las bases de datos utilizadas en todas las secciones y ejemplos del libro están disponibles gratuitamente en este repositorio.
